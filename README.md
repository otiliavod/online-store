# Online Store – Angular 21 + PrimeNG

A modern, scalable e-commerce storefront built with Angular 21 standalone components, PrimeNG v20, and Angular Signals.

## This project focuses on:

Clean UI architecture

Reusable components

Modern Angular patterns

Scalable structure for future backend integration


## Hosting link - Netlify

https://myonline-store-presentation.netlify.app/


## Tech Stack

Angular 21 (Standalone Components API)

PrimeNG v20

PrimeFlex

PrimeIcons

SCSS

Angular Signals (state management)

Angular Router

TypeScript

## Install dependencies

```bash
npm install
```


## Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.
